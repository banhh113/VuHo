# 🥋 CLB Võ Website

Sườn website CLB Võ để tiếp tục phát triển bằng VS Code.

## Kiến trúc
- ASP.NET Core MVC
- HTML5 / Razor
- CSS3
- Vanilla JavaScript
- Chuẩn bị sẵn thư mục cho SQL Server + Entity Framework Core

## Chạy dự án
```bash
dotnet restore
dotnet run
```

Mở URL mà terminal cung cấp.

## Các phần cần code tiếp
1. Kết nối SQL Server
2. Entity Framework Core
3. ASP.NET Core Identity cho `/admin`
4. CRUD bài viết
5. CRUD thành viên
6. CRUD sự kiện
7. CRUD gallery
8. CRUD thành tích
9. Upload ảnh
10. Hoàn thiện responsive và animation
